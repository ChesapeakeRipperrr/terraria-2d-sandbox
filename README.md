# ⛏ Terraria-Like 2D Sandbox Survival Game ⚔

一个用 HTML5 Canvas + JavaScript 编写的 2D 侧视沙盒生存游戏，玩法和画面效果贴近泰拉瑞亚（Terraria）。

## 🎮 特性

- **程序化地形生成** — Perlin 噪声生成 400×180 方块世界，含草地、沙漠、洞穴、矿石
- **挖掘与建造** — 鼠标左键挖掘方块，右键放置方块，不同方块需要不同等级的镐子
- **资源采集** — 木材、石头、铜矿、铁矿、金矿、煤矿、钻石
- **制作系统** — 15 种配方：木板 → 木剑/木镐 → 石剑/石镐 → 铁剑/铁镐 → 金剑 → 钻石剑
- **昼夜交替** — 120 秒一个完整周期，天空颜色平滑过渡，太阳/月亮运动
- **夜晚僵尸** — 天黑后生成僵尸追击玩家，白天会燃烧消失
- **战斗系统** — 武器攻击有挥砍动画、击退效果、伤害判定
- **光照系统** — 昼夜光照变化 + 火把光源 + 光线传播衰减
- **生命系统** — 心形血条、受伤无敌帧、坠落伤害、死亡重生
- **粒子效果** — 挖掘碎屑、攻击特效、血液飞溅

## 🚀 运行方式

### 方式一：直接打开
双击 `index.html` 即可在浏览器中运行。

### 方式二：本地服务器
```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 🎯 操作说明

| 按键 | 功能 |
|------|------|
| A/D 或 ←/→ | 左右移动 |
| 空格 或 W/↑ | 跳跃 |
| 左键 | 挖掘方块 / 挥武器攻击 |
| 右键 | 放置选中方块 / 吃食物 |
| E | 打开/关闭背包 |
| C | 打开/关闭制作台 |
| 1-0 | 选择快捷栏物品 |
| 滚轮 | 切换快捷栏 |
| F | 快速放置火把 |
| Q | 丢弃选中物品 |

## 🎮 玩法指南

1. **开局**：你有一把木镐、一把木剑、10 个火把和 3 个苹果
2. **采集木材**：砍伐地表树木获得木材
3. **制作工具**：按 C 打开制作台，先做木板（4 木板 = 1 木材），再做木剑/木镐
4. **挖矿升级**：用木镐挖石头和铜矿，升级到石镐后可以挖铁矿
5. **建造庇护所**：天黑前用木板/石头建房子，放火把照明
6. **生存夜晚**：僵尸会在夜晚生成，用武器击退它们
7. **深入地下**：更深处有金矿和钻石矿，可以制作更强的装备

## 🛠 技术栈

- HTML5 Canvas — 渲染
- JavaScript — 游戏逻辑（纯原生，无框架）
- CSS — UI 样式
- Perlin Noise — 程序化地形生成
